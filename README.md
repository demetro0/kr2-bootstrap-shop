# kr2-bootstrap-shop# TechStore — интернет-магазин компьютерной техники

## 1. Описание проекта

TechStore — учебный проект интернет-магазина компьютерной техники. Сайт позволяет просматривать каталог товаров, знакомиться с характеристиками выбранного товара и оформлять демонстрационную заявку.

Проект выполнен в рамках дисциплины «Фронтенд и бэкенд разработка».

## 2. Тема работы

Разработка интерфейса интернет-магазина с использованием CSS-фреймворка Bootstrap.

## 3. Используемые технологии

- HTML5 — структура страниц.
- CSS3 — дополнительные стили оформления.
- Bootstrap 5 — сетка, адаптивность и готовые компоненты интерфейса.
- JavaScript — поиск и сортировка товаров, проверка формы и отображение сообщения об успешной отправке.

Bootstrap подключён через CDN.

## 4. Структура проекта

- `index.html` — главная страница.
- `catalog.html` — каталог товаров.
- `product.html` — страница товара.
- `order.html` — форма оформления заявки.
- `css/custom.css` — дополнительные стили.
- `images/` — папка для изображений.
- `README.md` — описание проекта.
- `.gitignore` — список файлов, которые не нужно добавлять в Git.

## 5. Реализованные возможности

- Навигационная панель с переходами между страницами.
- Адаптивная сетка Bootstrap.
- Карточки товаров с описанием и ценой.
- Поиск товаров по названию.
- Сортировка товаров по цене.
- Страница с характеристиками товара.
- Форма оформления заявки.
- Проверка обязательных полей формы.
- Чекбокс согласия на обработку персональных данных.
- Модальные окна с дополнительными формами.
- Аккордеон с ответами на вопросы.
- Карусель популярных товаров на главной странице.
- Адаптация интерфейса под мобильные устройства.

## 6. Использованные компоненты Bootstrap

В проекте используются `container`, `row`, `col-*`, `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `form-control`, `form-select`, `input-group`, `form-check` и `accordion` и `carousel`.

Также применяются классы отступов, цветов, выравнивания и адаптивного отображения элементов.

## 7. Дополнительные улучшения

В дополнение к базовой структуре реализованы поиск и сортировка товаров на странице каталога, а также демонстрационная проверка формы с выводом сообщения об успешной отправке.

**Важно:** проект является демонстрационным. Данные формы не отправляются на сервер и не сохраняются в базе данных.
